This repository consist of all the puzzles related to an event held Friday October 23 by CDRU that I made

It is a murder mystery style event with mafia rules of 2 imposters (in universe they are AI), 1 detective (for hints), 1 medic (to protect)

During the day people would solve puzzles which point to imposters. 2 red herring puzzles (solutions would point to crew) and 2 pointing toward each imposter (to add chance into the mix if close).
The master spreadsheet document in actual exercises shows this
    (as well as fully automating the email puzzle provided both an imposter & crew answered)

The fakeposts correspond to one of these puzzles.

Hope these are interesting or helpful to you!
